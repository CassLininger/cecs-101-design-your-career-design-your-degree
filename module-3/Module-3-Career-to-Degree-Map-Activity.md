### Career 2

**Career Title:**
Network Security Specialist

**Brief Description** *(what does this person do day to day?):*
A Network Security Specialist protects an organization's network infrastructure from unauthorized access, attacks, and other security threats. Day-to-day responsibilities can include monitoring network traffic, managing security controls such as firewalls and intrusion detection systems, identifying vulnerabilities, protecting data, and responding to network security incidents. UT Knoxville specifically describes Network Security Specialists as professionals who design, implement, and manage network security measures.

**Typical Education Required:**
Typical Education Required:
A bachelor's degree in cybersecurity, computer science, information technology, or another related computer field is a strong preparation for this career. Related networking experience is also valuable.

**Key Skills Required** *(list at least 6):*
1. Network monitoring
2. Critical thinking
3. Troubleshooting
4. Problem solving
5. Active listening
6. Systems analysis

**Key Knowledge Areas Required:**
Important knowledge areas include computer hardware and software, networking and telecommunications, operating systems, network security, servers, access control, and cybersecurity. Knowledge of technologies such as Linux, Windows Server, firewalls, cloud platforms, PowerShell, Python, and network-management tools can also be useful. O*NET's current employer-posting data identifies Linux, Active Directory, Windows Server, Azure, PowerShell, firewall software, Python, and AWS among software skills appearing in postings for related network and systems occupations.
**Median Annual Salary:**
$134,050

**Job Growth Outlook** *(growing, stable, declining?):*
8% growth

**Typical Career Path** *(how do people enter and advance in this field?):*
A person can begin by studying cybersecurity, networking, computer science, or information technology and gaining experience through labs, internships, or entry-level IT and networking positions. They can progress into network administration or network security positions and eventually move into more advanced roles such as network security engineer, network architect, or cybersecurity manager.

**3 specific courses or experiences that would build skills for this career:**
1. CYBR 202
